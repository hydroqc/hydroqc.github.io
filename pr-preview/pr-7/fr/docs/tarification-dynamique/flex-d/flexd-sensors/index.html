Capteurs Flex D

Description des capteurs Flex D

Description des capteurs

Les entités suivantes sont créées pour le tarif DPC (Flex D). Les entités d’événements de pointe lisent leurs données depuis le calendrier dédié configuré dans l’intégration; consultez le blueprint Flex D pour les automatisations.

Avertissement

Les entités qui représentent l’état actuel (État DPC, Pointe critique active, Préchauffage actif) dépendent des événements du calendrier et de la mise à jour du coordinateur. Pour les automatisations qui doivent s’exécuter à une heure précise, privilégiez les entités d’horodatage (Début prochaine pointe, Fin prochaine pointe, Début prochain préchauffage).

Capteurs

EntitéValeursDescription
État DPCnormal / peak / critical_peak / off_seasonÉtat actuel de la période. off_season hors de la saison hivernale (1er décembre au 31 mars)
Début prochaine pointehorodatageDébut de la prochaine période de pointe
Fin prochaine pointehorodatageFin de la prochaine période de pointe
Début prochain préchauffagehorodatageDébut de la période de préchauffage avant la prochaine pointe (Diagnostic, désactivé par défaut)
Heures de pointenombreHeures critiques appelées jusqu’à maintenant cet hiver (Diagnostic). Attribut max: nombre maximal d’heures critiques
Jours d’hivernombreJours écoulés depuis le début de la période hivernale (Diagnostic). Attribut max: nombre total de jours d’hiver

Les entités de consommation bi-énergie Conso. prix supérieur, Conso. prix inférieur et Différence Flex D vs Tarif D sont aussi disponibles avec ce tarif; consultez la référence des capteurs.
